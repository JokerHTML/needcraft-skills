## Critical failures (any one = REVISE or REJECT, regardless of score)

- [ ] No unverified factual claim, fabricated tool feature, fake ranking, fake test, or misleading "best" claim
- [ ] No broken, unsafe, unofficial, or wrong-destination tool link; no unverified price or free-tier promise
- [ ] Exact prompt/steps present wherever a workflow is taught
- [ ] No copied creator work, reused clips without meaningful original contribution, or unclear rights
- [ ] No misleading income/viral/monetisation guarantee; no inaccurate platform-policy claim
- [ ] Required AI disclosure (or other platform disclosure) present where applicable
- [ ] No unreadable mobile text, deceptive thumbnail, fake product UI, or major production defect
- [ ] No identical mass-produced copy across platforms without native adaptation

## Pre-delivery checklist

- [ ] Claim ledger present; every claim has source URL + date + confidence; no UNVERIFIED figure stated as fact
- [ ] Every tool link opened (or re-checked) and lands on the official destination
- [ ] Prompt block complete (8 parts) wherever a workflow is taught
- [ ] Hands-on vs desk-researched label present and true
- [ ] "Last checked" date present
- [ ] Hook passes the 4 S's — Subject / Stakes / Speed / Clarity — and sits in the first line
- [ ] One CTA per platform version; no triple-ask closer
- [ ] Specificity floor: ≥1 number + ≥1 named entity + ≥1 concrete detail per 100 words
- [ ] No AI-tell phrases; em-dash ≤1 per 100 words; no emoji walls
- [ ] Character limits respected: X ≤280 weighted per post (Premium ≤25,000) · Threads ≤500 · IG caption ≤2,200 · Pinterest title ≤100, description ≤800 · LinkedIn ≤3,000 · Facebook: no published limit, check the composer
- [ ] X native thread (first post no link, ends with a thread marker; link in the reply). Threads link in first reply only + native topic tag
- [ ] Hashtags: IG ≤5, LinkedIn 0–1, others 1–3 where they help
- [ ] Visual checklist passed: full text scan done, mobile-readable, no fake UI, card and image agree, alt text / captions present
- [ ] AI disclosure checked; no income/viral guarantee; no fake ranking or "best" claim
