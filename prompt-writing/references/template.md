## Pre-publish checklist

- [ ] All 8 parts present
- [ ] Every placeholder explained AND filled once
- [ ] Expected output labelled as example if not generated
- [ ] Verification step present for factual claims
- [ ] Limitations visible, including data-privacy warning
- [ ] Tool/model availability re-checked today
- [ ] Prompt tested once, or marked "drafted, not yet run"
- [ ] One CTA only
