# Prompt Writing

Write copy-ready AI tutorial prompts in a fixed 8-part block, so a reader
can run the workflow without guessing.

## What it is

A method for tutorial posts that teach an exact prompt — role, context,
task, inputs, constraints, output structure, quality checks — with
placeholders explained and filled, an expected output, an iteration
prompt, and visible limitations. "Ask ChatGPT to do this" is incomplete
and never ships.

## Who it is for

Anyone writing AI tutorials, prompt posts, or workflow explainers for
social media, a blog, or a newsletter.

## Install

Copy this folder into your skills directory as `prompt-writing/`.
No dependencies.

## How to use

1. Start from `references/template.md` — the blank 8-part scaffold.
2. Write the prompt with role first, task second, output format last,
   and constraints instead of adjectives ("under 120 words, 5 bullets"
   beats "make it good").
3. Explain every placeholder AND fill each one once with a real example.
4. Label the expected output as an example if it was not actually
   generated by running the prompt.
5. Run the pre-publish quality gate in `SKILL.md` before shipping.

## Example

`SKILL.md` contains a complete worked example: a candle product-description prompt
shown end to end — all 8 parts, a filled placeholder table, a labelled
example output, an iteration prompt, and limitations.

## Disclaimer

A prompt is a starting point, not a guarantee: model behaviour changes
between versions. Never promise a prompt produces perfect, accurate, or
guaranteed results.
