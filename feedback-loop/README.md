# Feedback Loop

Turn every customer question, comment, objection, or refund into a classified, routed,
fixed, and verified improvement.

## What it is

A seven-step loop — capture, classify, root-cause, decide, fix, verify, log — with nine
defined classification labels, a worked guide to telling close labels apart, a response
template, SLA guidance, and a feedback-log template with a filled example entry.

## Who it is for

A solo creator or small team selling a digital product (guide, template, course, or
similar) who answers their own support mail and wants every message to either improve the
product or improve the listing — and to be able to prove which one it was.

## How to use

1. Read `SKILL.md` — the process, the nine label definitions, the response template,
   and the SLA guidance.
2. Write down your refund terms before your first sale (the skill recommends a
   fix-first shape inside a 30-day window; your terms are yours to set).
3. Create a feedback log at a path you choose. Copy the blank template from
   `examples/feedback-log-template.md`.
4. For each feedback item: capture it verbatim, classify it into exactly one label, check
   the listing before blaming the product, fix at the smallest effective level, verify by
   re-testing the exact customer scenario, and log it.

## Example

`examples/feedback-log-template.md` contains a blank log template and one filled example
entry (a CONFUSION item: a customer could not find the templates). The example entry is
illustrative, written for this skill — not a real customer's words.

## Install

Copy this folder into your skills directory and reference it by name whenever customer
feedback arrives. No build step, no API key, no account needed — just a support inbox,
the product files, and the listing.

## Disclaimer

This skill classifies and routes feedback; it does not decide product strategy and it
does not set your refund terms or legal position. Escalate refund disputes, legal or
compliance concerns, and fundamental-misrepresentation feedback to the product owner or
qualified advice instead of resolving them alone.
