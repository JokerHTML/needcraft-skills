# Human Reply

Write comment replies that read like they came from a real, sharp, caring human.

## What it is

A method for replying to comments on your own posts: the anti-AI core (what never appears
in a reply), language matching, voice guidance with positive examples, substance rules,
difficult-comment handling, first-hour passes, per-platform reply limits, and a logging
contract — with worked good-vs-bad example pairs in English and Roman Urdu.

## Who it is for

A creator, community manager, or agent replying to comments on their own posts, in
English or Roman Urdu (the principles transfer to any language you actually speak).

## How to use

1. Read `SKILL.md` — the anti-AI core first, then voice, substance rules, and the
   worked examples.
2. Read the comment twice before replying. Understand what is actually being asked.
3. Reply in the commenter's language, reference their actual words, make one specific
   useful point, then stop.
4. Log the reply (posted, draft, or skip with a reason) in one place you choose.
5. See `examples/reply-examples.md` for the full set of good-vs-bad pairs.

## Example

Comment: "Tried the first template, got no reply. Is the second one actually better?"

Good reply: "The second one got replies for me where the first didn't — the difference
is the subject line names their actual problem instead of the service. Try swapping just
that line first and see if the reply rate moves."

All examples in this skill were written for illustration. They are not real replies and
never received real engagement.

## Install

Copy this folder into your skills directory and reference it by name when replying to
comments. No build step, no API key, no account needed.

## Disclaimer

This skill governs voice and judgement, not reach — a good reply does not guarantee
engagement. Platform character limits in the skill are a snapshot checked in November
2026; verify the current limit before a reply that approaches it. Replies on other
people's posts are draft-only under this skill, never auto-posted.
