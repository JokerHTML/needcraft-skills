18 production skills from [NeedCraft](https://needcraft.pages.dev) — the exact systems used to research, write, design, publish, and verify NeedCraft's daily AI content across Instagram, Threads, X, Facebook, LinkedIn, Pinterest, and YouTube. **Free forever, MIT licensed.** Use them, fork them, improve them.

> **What this is:** every skill is a folder with a `SKILL.md` (the instructions your AI agent follows), a `README.md`, worked examples, and an MIT `LICENSE`. Install the whole bundle or one skill at a time — see [INSTALL.md](INSTALL.md).

> **What this is NOT:** the GTA VI Shorts Editing Skill is a separate gaming product with its own Pro Pack — it is not in this bundle.

## Install

```bash
# Whole bundle (after this repo is public)
npx skills add JokerHTML/needcraft-skills

# One skill only
npx skills add JokerHTML/needcraft-skills --skill top5-rankings
```

Works today from a local copy too — see [INSTALL.md](INSTALL.md) for the local-path commands (Claude Code, Codex, and generic agents).
