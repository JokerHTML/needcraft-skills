# Verification record

Copy this template for every published post. One record per post.

## Blank template

```text
Date/time:        [YYYY-MM-DD HH:MM, timezone]
Platform:         [e.g. Instagram]
Slot:             [e.g. tutorial carousel]
Live URL:         [URL returned by the publish call, or found in recent posts]
Text match:       [match / MISMATCH — describe]
Media check:      [images load full size / video plays full duration / FAIL — describe]
Link check:       [links only where allowed / FAIL — describe]
Formatting:       [clean / literal asterisks / broken unicode / collapsed breaks]
Visibility:       [logged-out view OK / second-account OK / not possible — owner view only]
Duplicate check:  [one copy / DUPLICATE — report both URLs]
First comment / self-reply: [exact URL present / n/a / FAIL — describe]
Status:           [PASS / FAIL]
Problem:          [none / describe the defect and what happens next]
```

## Filled example

```text
Date/time:        2026-11-16 17:04 PKT
Platform:         Instagram
Slot:             tutorial carousel
Live URL:         [post URL from the scheduled-list link]
Text match:       match — byte-for-byte vs tutorial-carousel.txt
Media check:      all 5 slides load at full size
Link check:       no raw link in body; product link in first comment as intended
Formatting:       clean — no literal asterisks, unicode intact, line breaks intact
Visibility:       logged-out private-window view OK
Duplicate check:  one copy only
First comment / self-reply: exact product URL present in first comment
Status:           PASS
Problem:          none
```
