# Pre-publish record

Copy this template for every slot. One record per slot, per platform.

## Blank template

```text
Date/time:        [YYYY-MM-DD HH:MM, timezone]
Platform:         [e.g. Instagram]
Slot:             [e.g. tutorial carousel]
Account checked:  [account display name — confirm before publishing]
Signed in as:     [yes / no — if no, STOP and report]
Caption file:     [filename — confirm it is the latest version]
Media file(s):    [filenames — confirm each opens, correct order]
Recent posts read: [how many, e.g. last 10 posts]
Duplicate check:  [clear / FOUND — stop if found]
Lag re-reads:     [read 1 time + result; read 2 time + result, if needed]
Notes:            [anything unusual]
```

## Filled example

```text
Date/time:        2026-11-16 14:02 PKT
Platform:         Instagram
Slot:             tutorial carousel
Account checked:  Brand Instagram account (display name confirmed)
Signed in as:     yes
Caption file:     tutorial-carousel.txt (latest version, 3 hashtags)
Media file(s):    slide-01.png … slide-05.png (all open, correct order)
Recent posts read: last 10 posts
Duplicate check:  clear — no matching caption or media live
Lag re-reads:     not needed — first read confirmed absence
Notes:            Scheduled via native scheduler for 17:00; slot confirmed
                  in the platform scheduled list.
```
