# Platform Policy, Monetisation & Disclosure

Keep every post inside current platform policy: correct AI disclosures,
honest monetisation claims, proper affiliate/sponsor disclosure, and no
policy claim stated without a re-check.

## What it is

A pre-publish policy check for creators posting to YouTube, Instagram,
Facebook, Threads, TikTok, X, Pinterest, and LinkedIn. It contains a
per-platform AI-disclosure matrix (label names, where to enable them,
re-check dates), a monetisation eligibility decision tree, affiliate and
sponsor disclosure wording templates for captions and on-screen text, and
an originality-rules summary from Meta's "Rewarding Original Creators"
(March 2026) and YouTube's reused-content policy — plus one worked
example of a post run through the whole checklist.

## Who it is for

Creators and agents publishing social content, especially posts that use
AI-generated media, mention money or monetisation, or link to a product.

## Install

Copy this folder into your skills directory as
`platform-policy-disclosure/`. No dependencies.

## How to use

1. Before a publishing cycle, re-check the official pages linked in
   `SKILL.md` — policies change, and the skill's verification dates show
   when each claim was last checked.
2. Run the post through the disclosure checklist.
3. If it mentions income, run the monetisation decision tree.
4. If it carries an affiliate or sponsored link, add disclosure wording
   from the templates — at the top of the caption, before any link.
5. If a policy claim is uncertain, label it, investigate, or do not
   publish.

## Example

`SKILL.md` includes a worked example: a 40-second "I tested 3 free AI
image tools" video with an affiliate link, run through every check, with
the verdict (publish) and the one change that would flip it.
