without a row.

test you ran. UNVERIFIED = second-hand, outdated, or not yet checked —
do not publish it, or label it as unverified.

## Card spec checklist (per card)

- [ ] Ranking badge (#1–#5) consistent across cards
- [ ] Tool name
- [ ] "Best for" line
- [ ] Key benefit
- [ ] Limitation
- [ ] Access-link cue
- [ ] Slide 1: hook + task + "last checked [DATE]"
- [ ] Final slide: how to choose + one CTA
- [ ] 7–10 slides, 1080×1350, slide 2 = second hook
- [ ] Asset states "Desk-researched — last checked [DATE]. No hands-on
      test yet." OR "Hands-on tested — [date]" with evidence shown

## Pre-publish checklist

- [ ] Five credible tools verified, or shortlist retitled honestly
- [ ] Claim ledger complete; no UNVERIFIED claim published as fact
- [ ] "Last checked [DATE]" filled with today's date; prices re-checked
- [ ] Score table published (or a readable summary of it)
- [ ] Sponsorship/affiliate relationship disclosed, if any; ranking
      independence stated
