# Trend Intelligence

A weekly, evidence-tagged scan of what is changing in your niche — so your content plan is fed by current reality, not recycled ideas.

## What it is

One repeatable routine: scan eight lanes (AI tool updates, user questions, creator problems, freelancer problems, content-creation problems, automation, digital products, platform changes), record each candidate with source and date, tag it **FACT**, **SIGNAL**, or **SPECULATION**, score it **product relevance × confidence** on a concrete 1–5 rubric, and output a dated scan file plus a top-5 briefing.

It is a research routine, not a publishing tool. It never writes, schedules, or publishes content.

## Who it is for

Creators, educators, and small teams publishing regularly in a fast-moving niche who want the week's plan grounded in what actually changed.

## How to use

1. Write down your niche, audience, and offer in one paragraph. Every ranking decision refers back to it.
2. Run the scan weekly (Monday works well) following `SKILL.md`.
3. Save the dated scan file in your research folder, e.g. `research/trend-scans/trend-scan-2026-11-16.md`.
4. Take the top-5 briefing into planning. A human reviews the angles before any candidate enters the plan.

## Example

See `examples/sample-scan-2026-11-16.md` — a filled scan file with five ranked candidates, all verified 2026-11-16, plus a top-5 briefing.

## Install

This is a skill (a `SKILL.md` playbook), not software. Copy the `trend-intelligence/` folder into your agent's skills directory and invoke it when planning content, or follow it manually as a checklist.
