# Changelog

## v1.0.0 — 2026-11-16

First public release of the NeedCraft Skills MEGA Bundle — all 18 polished NeedCraft skills, free under MIT.

- 18 skills, each with spec frontmatter (`name` + `description`), a README, worked examples, and an MIT LICENSE (LICENSE added to the 14 skill folders that lacked one).
- Real image examples/proof in 5 skills (18 images, all visually verified real NeedCraft outputs — no fabricated screenshots):
  - top5-rankings: full 8-slide "5 Free AI Tools, Ranked" Instagram carousel + Pinterest version (published live 16 Nov 2026).
  - carousel-thumbnail-design: 3 cards from a real carousel (cover, text card, brand end card).
  - prompt-writing: Pinterest asset from the 16 Nov 2026 Top 5 post.
  - video-script-retention: 3 storyboard frames (hook, problem, CTA) from NeedCraft reel-01.
  - post-publish-qa: real QC before/after pair (reel-01 frame 28, caught broken and fixed).
- `skills.sh.json` manifest grouping the 18 skills into 5 sections for the skills.sh repo page.
- The GTA VI Shorts Editing Skill is intentionally NOT in this bundle (separate gaming product).
- Internal-only skills (animated-reel, gumroad-regression-qa) are intentionally NOT in this bundle.
